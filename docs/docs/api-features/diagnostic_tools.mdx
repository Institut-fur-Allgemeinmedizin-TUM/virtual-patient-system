# Diagnostic Tools

The backend also includes endpoints for diagnostic tools. This endpoint for example contains some vital parameters
for the different patients.


## Usage
This allows students to make use of diagnostic tools they would also be able to use
as a doctor.

By storing the usage of these tools they can also be used for evaluation whether the student used too
many / unnecessary tools and should do better next time.

## Endpoint
The endpoint for the diagnostic tools is under ```/api/diagnostics/{case_id}```.

For further query parameters have a look at the [Swagger UI](https://virtual-patients-tum.com/api/docs).
