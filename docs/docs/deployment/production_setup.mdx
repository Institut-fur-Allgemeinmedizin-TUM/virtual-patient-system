# Production Setup Guide

This page covers the production-specific runtime checks that matter most after deployment.

## Deployment target

The backend is designed to run in Cloud Run with PostgreSQL on Cloud SQL. The docs site is served from the backend
when the Docusaurus build has been generated into `docs/build`.

## Authentication check

If you see `user_id = "anon"` in the database, authentication is not enabled in the running environment.
Set `REQUIRE_AUTH=true` for production deployments.

### Verifying It Works:

1. **Log out completely** (clear cookies)
2. **Log in with TUM credentials**
3. **Create a new session**
4. **Check database:** The new session should have your TUM ID (e.g., `ge38qap`) instead of "anon"
